# Code of Conduct

## Our pledge

This project is used in real social situations: parties, friend groups, people
who are tipsy, tired, or both. The standard is higher here than in most repos,
because the "users" are your actual friends.

We pledge to make participation in this project a harassment-free experience for
everyone, regardless of age, body size, visible or invisible disability, ethnicity,
sex characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## What counts as unacceptable

**Content behaviour.** Because this repo is a content project, these are the
substantive ones:

- Suggesting dares with physical risk, property damage, or tasks involving
  strangers, animals, or anyone not present.
- Suggesting content that targets someone's name, identity, health, body, trauma,
  or finances.
- Pushing to add a "dark dare tier" or to remove the 18+ gate on the Spicy deck.
- Sexualising minors, in any tier, ever. This is an instant ban with no appeal.

**Behaviour.** Harassment, insults, sexualised attention or advances, deliberate
intimidation, publishing others' private information, and sustained disruption.

**Scope.** Content review happens in issues and PRs. That is where the rules above
apply most directly.

## Reporting

Report a problem by opening an issue, or contact the maintainer privately through
the repository owner's GitHub profile if the issue involves the maintainer or is
unsafe to make public. Reports are handled confidentially.

## Enforcement

Maintainer response, in escalating order:

1. **Correction** — a private note explaining what was wrong.
2. **Warning** — a warning with consequences for continued behaviour.
3. **Temporary ban** from all interaction.
4. **Permanent ban** from public interaction.

Severity is judged on impact to the project and its users, not on intent. An
accidental harmful card suggestion is a correction, not a ban; deliberately
adding a dangerous dare is a permanent ban.

## Scope note

This Code of Conduct governs the **repository** — issues, pull requests,
discussions, and code review. It cannot govern how people behave at an actual
party. Be decent to each other out there; that's the actual point of this thing.
